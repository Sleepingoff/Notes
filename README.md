# Notes

강의 자료를 읽고 필기하며, 로컬 AI로 시험지에서 문제를 추출해 풀 수 있는 데스크톱 앱입니다. macOS와 Windows를 지원합니다.

## 최소·권장 사양

다음은 **로컬 AI 문제 추출까지 사용할 때의 준비 기준**입니다. 메모리와 저장 공간의 권장값은 기본 모델 기준의 보수적인 안내이며, 모든 기기에서 검증한 실행 한계는 아닙니다.

| 항목 | 최소 준비 기준 | 권장 |
| --- | --- | --- |
| 운영체제 | macOS 14 이상 / Windows 10 22H2 이상(64비트) | 최신 보안 업데이트가 적용된 macOS / Windows 11 |
| 프로세서 | Apple Silicon 또는 Intel Mac / Windows x64 CPU | Apple M 시리즈 / GPU 가속을 사용할 수 있는 Windows PC |
| 시스템 메모리 | 기본 8B 모델 사용 시 16GB 이상 | Mac 통합 메모리 24GB 이상 / Windows RAM 32GB 이상 |
| 여유 저장 공간 | 20GB 이상, 학습 자료 용량 별도 | SSD 30GB 이상, 학습 자료 용량 별도 |
| GPU | 필수 아님. CPU로 추출하면 매우 느릴 수 있음 | Apple Silicon GPU / Ollama 지원 GPU, 기본 모델은 VRAM 12GB 이상 권장 |

운영체제와 GPU 지원 조건은 [Ollama macOS 안내](https://docs.ollama.com/macos), [Windows 안내](https://docs.ollama.com/windows)를 기준으로 합니다. Intel Mac에서는 Ollama가 CPU로 동작합니다. PDF 열람·필기와 이미 추출된 문제 풀이는 AI 모델을 실행하지 않고도 사용할 수 있습니다.

### 저장 공간과 모델 선택

| 구성요소 | 필요한 공간 |
| --- | --- |
| Notes 앱 | 약 0.5GB (현재 macOS Apple Silicon 빌드 기준, 버전·운영체제에 따라 다름) |
| Ollama | 별도 설치 공간 필요. Windows 설치 파일 구성은 최소 4GB의 공간 필요 |
| 기본 모델 `qwen3-vl:8b-instruct` | 다운로드 약 6.2GB |
| 작은 모델 `qwen3-vl:4b-instruct` | 다운로드 약 3.3GB |
| PDF·필기·추출 결과 | 등록한 자료와 추출한 페이지 수에 따라 계속 증가 |

모델 용량은 [8B 모델](https://ollama.com/library/qwen3-vl:8b-instruct)과 [4B 모델](https://ollama.com/library/qwen3-vl:4b-instruct)의 기본 양자화 버전 기준입니다. **다운로드 용량과 실행 메모리는 다릅니다.** 실행할 때는 모델 외에도 이미지 처리와 컨텍스트용 메모리가 필요합니다. 여러 모델을 설치하면 저장 공간도 추가로 사용합니다.

공간이나 메모리가 부족하면 `ollama pull qwen3-vl:4b-instruct`로 작은 모델을 설치한 뒤 Notes의 AI 설정에서 모델명을 변경하세요. 작은 모델은 복잡한 지문·표의 인식 품질이 달라질 수 있습니다. 사용하지 않는 모델은 `ollama rm 모델명`으로 제거할 수 있습니다.

## 1. 앱 설치

[Releases](https://github.com/Sleepingoff/Notes/releases)에서 운영체제에 맞는 설치 파일을 내려받습니다.

| 운영체제 | 설치 파일 | 설치 방법 |
| --- | --- | --- |
| Mac · Apple Silicon (M1 이상) | `Notes-버전-mac-arm64.dmg` | 열어서 Notes를 응용 프로그램 폴더로 옮깁니다. |
| Mac · Intel | `Notes-버전-mac-x64.dmg` | 열어서 Notes를 응용 프로그램 폴더로 옮깁니다. |
| Windows · 64비트 | `Notes-버전-win-x64.exe` | 실행한 뒤 설치 안내를 따릅니다. |

현재 인증서 없이 배포하는 macOS 버전은 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. 처음 실행이 차단되면 파일 출처를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용하세요. Windows에서도 서명되지 않은 설치 파일에 대한 경고가 나타날 수 있습니다.

릴리즈가 아직 없다면 [소스 실행 안내](docs/DEVELOPMENT.md)를 이용할 수 있습니다.

## 2. 로컬 AI 준비

문제 추출에는 [Ollama](https://ollama.com/download)와 이미지 인식이 가능한 로컬 모델이 필요합니다. AI 서비스의 API 키나 유료 구독은 필요하지 않습니다. 앱 설치 파일에 모델은 포함되어 있지 않습니다.

1. Ollama를 설치하고 실행합니다.
2. 터미널(macOS) 또는 PowerShell(Windows)에서 모델을 내려받습니다.

   ```sh
   ollama pull qwen3-vl:8b-instruct
   ```

3. Notes를 실행하고 **AI 설정**을 엽니다.
4. 서버 주소를 `http://127.0.0.1:11434`, 모델을 `qwen3-vl:8b-instruct`로 설정합니다.
5. 연결 확인을 눌러 모델을 사용할 수 있는지 확인합니다.

다른 로컬 비전 모델을 설치했다면 AI 설정에서 해당 모델명을 입력할 수 있습니다. 설치된 모델명은 `ollama list`로 확인합니다. 서버 주소는 같은 컴퓨터에서 실행하는 Ollama 주소만 지원합니다.

기본 모델 다운로드에는 약 6.2GB의 저장 공간이 필요하며, 실행 시 추가 메모리를 사용합니다. 추출 속도와 사용 가능한 모델 크기는 컴퓨터 사양에 따라 달라집니다. 추출하는 동안 Notes와 Ollama를 실행해 두세요. 모델을 내려받은 뒤에는 문제 추출에 인터넷 연결이 필요하지 않습니다.

## 3. 과목과 강의 자료 등록

1. 과목명을 입력해 과목을 만듭니다.
2. **강의 자료 보기 → PDF 추가**로 강의 파일을 등록합니다. PDF, HWP, HWPX를 사용할 수 있습니다.
3. 여러 강의는 하나의 PDF로 합쳐집니다. 목차에서 강의 이름, 순서와 포함 여부를 변경할 수 있습니다.

과목 이름을 바꾸거나 삭제하려면 과목에 마우스를 올려 수정·삭제 아이콘을 사용합니다. 과목을 삭제하면 해당 과목의 자료와 학습 기록도 삭제됩니다.

HWP/HWPX는 PDF로 변환해 사용합니다. 복잡한 수식이나 표는 원본과 다르게 표시될 수 있으므로 변환 결과를 확인하세요.

## 4. 문제 추출과 풀이

1. **문제은행 관리**에서 시험지를 등록합니다. 등록하면 문제 추출이 시작됩니다.
2. 시험의 연도와 학기가 올바른지 확인하고, 잘못 인식했다면 수정합니다.
3. **문제 풀기**로 추출된 문제를 풉니다. 일부 페이지가 실패해도 완료된 페이지의 문제는 풀 수 있습니다.
4. 새로 풀고 싶으면 **새 회차 시작**으로 풀이 회차를 추가합니다.

과목명·연도·학기에 맞는 정답표가 하나로 정해지면 자동 적용됩니다. 과목명은 띄어쓰기를 무시해 비교합니다. 학년별 정답표가 여러 개라면 사용할 학년을 선택합니다. 제공되는 정답표는 2014~2020년 자료이며, 모든 시험과 과목을 포함하지는 않습니다.

정답표가 없는 시험은 **정답표**의 문항별 칸에 직접 입력합니다. 복수 정답은 `1,2`처럼 입력하며, 인정되는 보기 중 하나를 고르면 정답으로 채점합니다. 정답이 없는 문항은 채점 대기로 남습니다. **복사하기**로 정답표를 복사할 수 있습니다.

문제의 해설에 메모와 강의 페이지를 연결할 수 있습니다. 보기 선택, 정답표, 메모와 수정 내용은 자동 저장됩니다.

## 5. 잘못 추출된 문제 수정

**문제 수정하기**에서 원본 페이지를 보며 문제 내용과 보기를 수정합니다. AI로 다시 읽으려면 다음 순서로 진행합니다.

1. **문제 영역**을 선택하고 원본에서 해당 문제의 영역을 드래그합니다.
2. 그림이나 표가 필요하면 **이미지 영역**으로 필요한 영역을 지정합니다. 여러 개 지정할 수 있습니다.
3. 문제 번호를 확인하고 **선택 영역 다시 추출**을 누릅니다.
4. 결과를 원본과 비교하고 필요한 부분을 수정합니다.

추출에 실패한 페이지는 **실패 페이지 직접 작성**으로 복구할 수 있습니다. 직접 작성할 때는 다음 형식을 사용합니다.

```md
12) 문제 내용

- [ ] 첫 번째 보기
- [ ] 두 번째 보기
- [ ] 세 번째 보기
- [ ] 네 번째 보기
```

AI가 지문, 보기, 그림을 잘못 인식할 수 있으므로 학습 전에 원본과 비교해 주세요.

## 6. PDF 필기와 다운로드

PDF에서 펜, 형광펜, 텍스트와 지우개를 사용할 수 있습니다. 텍스트는 PDF 위에 바로 입력하며, 기존 텍스트 내부를 누르면 내용을 수정합니다. 테두리를 드래그하면 위치를 옮기고 조절점으로 영역 크기를 바꿉니다.

필기는 자동 저장됩니다. **필기 포함 PDF**를 준비해 내려받으면 필기를 포함한 파일을 얻을 수 있습니다. 원본 PDF와 문제 Markdown·이미지 ZIP도 내려받을 수 있습니다.

## 7. 데이터 백업

자료와 학습 기록은 컴퓨터의 데이터 폴더에 저장됩니다. **파일 → 데이터 폴더 열기**로 위치를 확인할 수 있습니다.

- macOS: `~/Library/Application Support/Notes/workspace`
- Windows: `%APPDATA%\Notes\workspace`

백업할 때는 Notes를 종료하고 `workspace` 폴더 전체를 복사하세요. 복원할 때도 앱을 종료한 상태에서 해당 폴더를 교체합니다. PDF나 ZIP 내보내기만으로는 풀이 기록과 편집 가능한 필기 데이터가 모두 백업되지 않습니다.

## 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| Ollama 연결 실패 | Ollama가 실행 중인지, AI 설정의 서버 주소가 맞는지 확인합니다. |
| 모델을 찾을 수 없음 | `ollama list`로 모델명을 확인하거나 `ollama pull`로 설치합니다. |
| 비전 모델이 아니라는 안내 | 이미지 입력을 지원하는 로컬 모델을 선택합니다. |
| 메모리 부족 또는 응답 지연 | 다른 앱을 종료하거나 더 작은 비전 모델을 사용합니다. |
| 일부 페이지 추출 실패 | 문제은행의 오류 상세를 확인하고 재시도하거나 직접 수정합니다. |

앱을 재시작한 뒤 **추출 다시 시도**를 누르면 완료된 페이지를 유지하며 실패한 페이지를 다시 처리합니다.

설치·사용 문제가 해결되지 않으면 [Issues](https://github.com/Sleepingoff/Notes/issues)에 운영체제, 앱 버전과 오류 메시지를 남겨 주세요. 개인 자료나 비밀번호는 첨부하지 마세요.
